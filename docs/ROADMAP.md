# PrepOS — Roadmap

## Phase 0 — Bootstrap
Repository, FastAPI/Next.js skeletons, Docker Compose, PostgreSQL, Redis, CI, linting, migrations, auth foundation and documentation.

## Phase 1 — Exam configuration
Exam, stage, paper, section, question-type, marking-scheme and syllabus models/APIs. Seed one sample exam configuration.

## Phase 2 — Resource library
Secure upload, metadata, object storage abstraction, async extraction, page mapping, processing states, retries and tests.

## Phase 3 — Grounded AI tutor
Chunking, embeddings, pgvector retrieval, source/page citations, answer generation, insufficient-evidence behavior and evaluation dataset.

## Phase 4 — Question bank and test engine
Question CRUD, answer keys, test assembly, timed attempts, autosave, submission, deterministic scoring and review.

## Phase 5 — Learning loop
Incorrect-answer queue, topic-level performance, revision scheduling and basic planner.

## Phase 6 — Adaptive intelligence
Recommendation logic, spaced repetition, difficulty adaptation and model-assisted question drafting with human review.

## Phase 7 — Production readiness
Security, privacy, performance, accessibility, observability, backups, deployment, documentation and demo data.
